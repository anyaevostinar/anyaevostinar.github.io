## Overview
Because evolution is an algorithm that can occur whenever its required components are in place, we can create systems that evolve via natural selection in software and get some things that are the closest we've seen so far to "alive" in a digital system.


## Basic Learning Objectives
Before class, you should be able to:
* Explain how digital evolution is an instantiation of evolution
* Explain the difference between implicit and explicit fitness

## Advanced Learning Objectives
After class, you should be able to:
* Implement the components necessary for a simple digital evolution system using Empirical
