## Overview
We're now going to switch to using a key feature of Empirical, the `World` class, which does much of the organization of organisms in a population for you. Today is all about getting familiar with how to use this new component.

## Basic Learning Objectives

Before class you should be able to:
* Explain how you can add organisms and manage their dynamics in an Empirical World
* Identify how data is collected and output using Empirical


## Advanced Learning Objectives

After class, you should be able to:
* Use Empirical's World to manage a population of organisms
* Output data of your choice from the World

## Reading
You should read the following to achieve the basic learning objectives (note, these are from a previous time that I taught the class, please take note of anything confusing or typos!):
* [Empirical World Intro](https://anyaevostinar.github.io/classes/361-w21/empirical_intro)
